# Weapon-Inventory-Management

A secure, full-stack web application designed to manage the distribution and record-keeping of weapons within an organization. The system supports daily tracking, issuance logs, and officer-level verification with digital signatures.

**Role:** Junior Developer  
**Tech Stack:** React.js, Node.js, Express.js, MongoDB, Bootstrap

---

## Description

As a Junior Developer, I contributed to building a secure and efficient inventory system that helps streamline the process of issuing and returning weapons. The system was designed for real-time tracking, signature-based approval, and robust record maintenance to ensure accountability and transparency.

---

## Key Features

- **Daily Tracking:** Log weapon issuance and return dates automatically.
- **Officer Signatures:** Captures digital signatures of issuing and approving officers.
- **Role-Based Access:** Admins, officers, and inventory managers have specific permissions.
- **Responsive Design:** Built with Bootstrap for compatibility across all devices.
- **Database Integration:** Stores records securely using MongoDB.
- **RESTful API:** Built with Express and Node.js for backend operations.

---

## Technologies Used

- **Frontend:** React.js, Bootstrap  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** Role-based access and secure login (if applicable)

## Setup Instructions

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/weapon-inventory-system.git
    cd weapon-inventory-system
    ```

2. Install backend dependencies:
    ```bash
    cd server
    npm install
    ```

3. Install frontend dependencies:
    ```bash
    cd ../client
    npm install
    ```

4. Start the backend server:
    ```bash
    npm start
    ```

5. Start the frontend:
    ```bash
    npm start
    ```

> **Note:** Ensure MongoDB is running on your system before starting the backend server.
